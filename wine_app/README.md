# Подборка вин

Приложение оценивает вероятность экспертной оценки вина не ниже 7. Один порог из боковой панели применяется к отдельному вину, к загруженному CSV и к метрикам на отложенной выборке.

## Запуск

Проверено на Python 3.12. Откройте терминал в папке `wine_app`.

```bash
python -m venv .venv
```

Активируйте окружение. В Windows PowerShell используйте `.venv\Scripts\Activate.ps1`, в macOS или Linux — `source .venv/bin/activate`.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Для пакетной оценки CSV должен содержать те же 12 признаков, что и `test.csv`, без `target`. В `is_red` используйте 1 для красного вина и 0 для белого.

## Публикация на Streamlit Community Cloud

1. Загрузите папку `wine_app` целиком в свой GitHub-репозиторий.
2. В [Streamlit Community Cloud](https://share.streamlit.io/) выберите **Create app** и укажите репозиторий, ветку и путь `wine_app/app.py`. Если вы загрузили содержимое папки в корень репозитория, укажите `app.py`.
3. В **Advanced settings** выберите Python 3.12. Нажмите **Deploy**, проверьте вкладки и вставьте URL приложения в последнюю ячейку ноутбука.

[Документация по публикации](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app)

## Кэширование

`st.cache_resource` хранит загруженный пайплайн как общий объект сервера. При вызове `joblib.load` без кэша модель повторно читалась бы с диска и десериализовалась на каждом перезапуске скрипта. Для тестовой таблицы и массива вероятностей используем `st.cache_data`: он хранит сериализуемые результаты и возвращает копии. Порог не входит в ключ кэша вероятностей, поэтому перемещение ползунка меняет только решение и вычисляемые по нему метрики.
